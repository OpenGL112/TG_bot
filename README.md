# TG_bot — бот записи в салон

Telegram-бот на aiogram 3 + SQLite: клиент выбирает услугу, дату и время, администратор получает уведомление о записи и отмене.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполнить BOT_TOKEN и ADMIN_ID
./start.sh
```

База `appointments.db` создаётся автоматически. При старте и затем раз в сутки бот дополняет расписание на `BOOKING_DAYS_AHEAD` дней вперёд по рабочим часам и дням из `.env`. Старая база (без `bookings.slot_id`) мигрирует автоматически.

## Как пользоваться

Всё управление — кнопками, команды знать не нужно. Внизу экрана постоянно видна клавиатура «📅 Записаться», «📋 Мои записи», «❌ Отменить запись», «ℹ️ Помощь». Запись проходит в 4 шага (услуга → день → время → подтверждение), сначала предлагаются ближайшие свободные дни, полный календарь — по кнопке «📅 Другая дата». Отмена записи тоже требует подтверждения. На любой текст бот отвечает подсказкой и снова показывает клавиатуру.

Команды `/start`, `/help`, `/book`, `/my_bookings`, `/cancel_bookings` продолжают работать для тех, кто к ним привык.
